🚀 HackMateAI

HackMateAI is a hackathon companion application designed to help teams generate ideas, evaluate them, shortlist the best ones, and plan execution efficiently.
It focuses on decision-making, productivity, and user experience during fast-paced hackathons.

🎯 Problem Statement

During hackathons, teams often struggle with:

Generating strong, feasible ideas

Deciding which idea to pursue

Managing multiple ideas and discussions

Quickly planning tasks within limited time

HackMateAI addresses these challenges by providing a structured workflow for ideation, evaluation, and project shortlisting.

💡 Solution Overview

HackMateAI acts as a central idea management tool for hackathon teams.
It helps users generate domain-specific ideas, evaluate them using clear metrics, and shortlist promising projects using an intuitive and visually appealing interface.

✨ Features
🔹 Idea Generation

Generate hackathon ideas based on selected domains such as:

Healthcare

Education

Climate

Productivity

🔹 Task Planner

Automatically generates a task plan based on project type (AI / Web)

Helps teams quickly understand development flow

🔹 Idea Evaluation Score

Evaluate ideas using three metrics:

Innovation

Feasibility

Impact

Generates a total score and qualitative feedback

Helps teams objectively compare ideas

🔹 Liked / Shortlisted Projects

Like projects to shortlist them

Remove (unlike) projects easily

Maintains a clean list of selected ideas

🔹 Clean & Modern UI

Card-based layout

Sidebar configuration

User-friendly workflow

Designed to look like a real product MVP
